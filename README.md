## About the course

This practical course connects established email-marketing principles with Claude Cowork. Learners work from a grounded campaign brief, manage audience data and segmentation, create brand-consistent email content, design approval-controlled automation, and evaluate campaign evidence without exposing customer data or automating unsupported claims.

The course aligns with Skills Framework TSC `ICT-SNM-3006-1.1 Integrated Marketing` and uses a synthetic Northstar Fitness campaign throughout the labs.

## Learning outcomes

By the end of the course, learners will be able to:

- propose an email-marketing strategy aligned with an organisation's objectives and target customers;
- manage newsletter audiences using consent, data-quality, segmentation, and personalisation controls;
- develop effective campaign content and reusable Custom Skills with Claude Cowork;
- design safe email-marketing automation using scoped connectors, human approval, and release evidence; and
- evaluate campaigns and A/B tests using reconciled metrics, caveats, and defensible optimisation decisions.

## Topics covered

1. Email Marketing Strategy and Campaign Planning with Claude Cowork
2. Audience Management, Segmentation and Personalisation
3. Creating Email Content and Campaigns with Custom Claude Skills
4. Email Marketing Automation with Claude Cowork and MCP Tools
5. Campaign Analytics, A/B Testing and Performance Optimisation
